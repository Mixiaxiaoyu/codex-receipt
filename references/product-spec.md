# Product Spec

## Product Definition

CODEX RECEIPT reads accessible Codex work traces, summarizes usage behavior, computes a **Codex Working Persona**, and renders a skinned long receipt artifact.

The result is a personal local activity summary, not official billing.

Required visible disclaimer:

```text
LOCAL RECORD
PERSONAL SUMMARY
NOT OFFICIAL BILLING
```

Visible time tickets must use:

```text
OUTPUT TIME
YYYY-MM-DD HH:MM
```

## Architecture

1. Parse local Codex history.
2. Aggregate statistics and persona.
3. Create an AI illustration prompt for the persona.
4. Pixel-process a supplied AI illustration, or use a deterministic simple placeholder for demo/testing.
5. Compose `receipt.html` on the cleaned receipt texture skin.
6. Screenshot the HTML with a headless browser.
7. Validate the output.

The full receipt is never generated by image generation. Only the persona illustration may come from AI.

## Skin Assets

The installed skill may include template skin PNG files under `assets/`. These are runtime assets. Raw reference screenshots are forbidden.

Allowed:

- `receipt-skin-top.png`
- `receipt-skin-mid.png`
- `receipt-skin-bottom.png`
- `stamp-output-time.png`
- `receipt-skin-manifest.json`

Forbidden:

- original reference screenshots
- mood/reference PNGs
- old demo direction images
- arbitrary copied inspiration images
