# Product Spec

## Product Definition

CODEX RECEIPT reads accessible Codex work traces, summarizes usage behavior, computes a **Codex Working Persona**, and renders a skinned long receipt artifact.

The result is a personal local activity summary, not official billing.

Required visible disclaimer:

```text
LOCAL RECORD
PERSONAL SUMMARY
NOT OFFICIAL BILLING
```

Visible time tickets must use:

```text
OUTPUT TIME
YYYY-MM-DD HH:MM
```

## Architecture

1. Parse local Codex history.
2. Aggregate statistics and persona.
3. Create an AI illustration prompt for the persona.
4. Generate the persona illustration during the user-facing skill run.
5. Pixel-process the generated or supplied AI illustration. Use a deterministic simple placeholder only for demo/testing or an explicitly accepted fallback.
6. Compose `receipt.html` on the cleaned receipt texture skin.
7. Screenshot the HTML with a headless browser.
8. Validate the output.

The full receipt is never generated by image generation. Only the persona illustration may come from AI.

## Skin Assets

The installed skill may include template skin PNG files under `assets/`. These are runtime assets. Raw reference screenshots are forbidden.

Allowed:

- `receipt-skin-top.png`
- `receipt-skin-mid.png`
- `receipt-skin-bottom.png`
- `stamp-output-time.png`
- `receipt-skin-manifest.json`

Forbidden:

- original reference screenshots
- mood/reference PNGs
- old demo direction images
- arbitrary copied inspiration images

## Invocation Behavior

User-facing skill runs should prepare the data, generate `persona-illustration-raw.png` from `persona-illustration-prompt.txt`, and render the receipt with that asset in one continuous flow. The prompt file is an implementation artifact, not the final handoff. Placeholder illustration output is acceptable only for automated tests, benchmarks, development demos, or when image generation is unavailable and the user explicitly accepts the fallback.

English is the default output language. If the user includes `@cn`, asks for Chinese, or uses the `cn` command, set `language: zh-cn` in `receipt-data.json` and render Chinese labels, section headings, persona title, notes, and footer text. In PowerShell, document the literal CLI alias as quoted `'@cn'`; unquoted `@cn` is shell syntax. Keep `CODEX RECEIPT` and the textured `OUTPUT TIME` stamp identity stable.

## Token Accuracy

Token totals are local-history statistics, not official billing totals. If trusted per-turn token usage is present and passes sanity checks, show `TOKEN`. If exact usage is missing, inconsistent, or appears cumulative/duplicated, preserve the observed local value in machine-readable reports but show the receipt row as `TOKEN EST.` and include `TOKEN COV` as `<turns_with_token_data>/<total_turns>`. Do not present estimated token totals as exact usage.
