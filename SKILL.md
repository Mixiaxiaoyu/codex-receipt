# Codex Receipt

## Purpose

CODEX RECEIPT reads allowed local Codex history sources, computes trustworthy activity statistics, derives a non-clinical **Codex Working Persona**, and renders a shareable long receipt artifact.

This v5 skill uses the correct production architecture:

1. A cleaned **receipt texture skin** is derived from the approved receipt material after old text, barcode, red stamp, and illustration are removed.
2. `receipt.html` uses that texture like a game UI skin: fixed top, repeated middle, fixed bottom.
3. HTML/CSS lays data, dotted rows, red textured `OUTPUT TIME` stamp, barcode, and footer onto that skin.
4. A persona illustration is generated by AI during the skill run, pixel-processed, and placed into a fixed illustration slot before final handoff.

The skill may include template skin assets such as `assets/receipt-skin-top.png`, `assets/receipt-skin-mid.png`, `assets/receipt-skin-bottom.png`, and `assets/stamp-output-time.png`. These are runtime texture assets, not raw reference images. Do not bundle the original screenshots/reference images or intermediate full blank sources.

## Visual Contract

- The final receipt background must come from the cleaned receipt texture skin, not from hand-drawn procedural imitation.
- Receipt width is fixed at 1080 px canvas / 560 px paper. Receipt height is dynamic.
- The paper middle stretches or tiles vertically when content changes.
- The final PNG is rendered from `receipt.html` by a headless browser.
- The `OUTPUT TIME` stamp uses a transparent distressed stamp texture plus dynamic time text.
- The original reference screenshots must not remain in the skill package.
- The full receipt is never generated by image generation.
- Image generation is used only for the persona illustration asset.
- User-facing skill runs must include a generated persona illustration by default. Do not hand off a placeholder receipt unless image generation is blocked and the user explicitly accepts a development fallback.
- English is the default receipt language. If the user includes `@cn` or asks for Chinese output, set `language=zh-cn` for both prepare and render.

## Zero-Input Behavior

When a user triggers this skill with a short request such as "run this skill", "generate my receipt", or "Codex Receipt", start the full production workflow immediately. Do not ask follow-up questions, do not explain the process first, and do not stop after `prepare`.

Use defaults unless the user says otherwise:

- `period=all`
- `out=output`
- `language=en`
- Generate a fresh AI persona illustration for this run.
- Render the final receipt with that generated illustration.
- Hand off the final file paths and any real blockers only after generation or failure.

Only pause before rendering when local history access is unavailable, image generation is unavailable, required runtime assets are missing, or the user explicitly asks for a plan, explanation, demo-only run, or no file changes.

## Workflow

1. Discover allowed Codex history sources.
2. Parse and aggregate statistics with privacy protections.
3. Compute the Codex Working Persona.
4. Run `python -m codex_receipt prepare --period all --out output` to write `receipt-data.json` and `persona-illustration-prompt.txt` without rendering a placeholder. For Chinese output, add `--language zh-cn`.
5. Immediately generate `output/persona-illustration-raw.png` from `persona-illustration-prompt.txt` using the available image-generation tool. This is part of the normal skill run, not an optional add-on for the user.
6. Run `python -m codex_receipt render --out output --persona-illustration output/persona-illustration-raw.png` so the generated illustration is pixel-processed and placed into the receipt. For Chinese output, add `--language zh-cn` or use a payload prepared with `--language zh-cn`.
7. Compose `receipt.html` using the texture skin and fixed layout rules.
8. Screenshot the HTML with a headless browser to create the final PNG.
9. Validate output dimensions, skin assets, dynamic height, privacy reports, visual contract, and `ai_illustration_supplied: true`.

Use the deterministic placeholder path only for automated tests, benchmark runs, or explicitly requested development demos.

## Commands

```bash
python -m codex_receipt prepare --period all --out output
python -m codex_receipt render --out output --persona-illustration output/persona-illustration-raw.png
python -m codex_receipt prepare --period all --out output-cn --language zh-cn
python -m codex_receipt render --out output-cn --language zh-cn --persona-illustration output-cn/persona-illustration-raw.png
python -m codex_receipt cn --period all --out output-cn --persona-illustration output-cn/persona-illustration-raw.png
python -m codex_receipt '@cn' --period all --out output-cn --persona-illustration output-cn/persona-illustration-raw.png
python -m codex_receipt demo --out output
python -m codex_receipt generate --period all --out output --persona-illustration output/persona-illustration-raw.png
python -m codex_receipt inspect-coverage
python -m codex_receipt clear-cache --out output
python -m codex_receipt reset-identity --out output
python -m codex_receipt benchmark --out output
```

`--specimen-asset` remains as a backward-compatible alias for `--persona-illustration`. In chat, `@cn` means Chinese output. In PowerShell, quote it as `'@cn'` or use the plain `cn` command.

## Handoff

Report generated files or blockers first. Mention coverage limits, privacy warnings, visual-check status, whether `ai_illustration_supplied` is true, and whether the receipt used the HTML texture skin. If image generation was unavailable, say that clearly and do not present the placeholder as the normal final result.
