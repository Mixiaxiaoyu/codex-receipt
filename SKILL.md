# Codex Receipt

## Purpose

CODEX RECEIPT reads allowed local Codex history sources, computes trustworthy activity statistics, derives a non-clinical **Codex Working Persona**, and renders a shareable long receipt artifact.

This v5 skill uses the correct production architecture:

1. A cleaned **receipt texture skin** is derived from the approved receipt material after old text, barcode, red stamp, and illustration are removed.
2. `receipt.html` uses that texture like a game UI skin: fixed top, repeated middle, fixed bottom.
3. HTML/CSS lays data, dotted rows, red textured `OUTPUT TIME` stamp, barcode, and footer onto that skin.
4. A persona illustration is generated separately by AI, pixel-processed, and placed into a fixed illustration slot.

The skill may include template skin assets such as `assets/receipt-skin-top.png`, `assets/receipt-skin-mid.png`, `assets/receipt-skin-bottom.png`, and `assets/stamp-output-time.png`. These are runtime texture assets, not raw reference images. Do not bundle the original screenshots/reference images or intermediate full blank sources.

## Visual Contract

- The final receipt background must come from the cleaned receipt texture skin, not from hand-drawn procedural imitation.
- Receipt width is fixed at 1080 px canvas / 560 px paper. Receipt height is dynamic.
- The paper middle stretches or tiles vertically when content changes.
- The final PNG is rendered from `receipt.html` by a headless browser.
- The `OUTPUT TIME` stamp uses a transparent distressed stamp texture plus dynamic time text.
- The original reference screenshots must not remain in the skill package.
- The full receipt is never generated by image generation.
- Image generation is used only for the persona illustration asset.

## Workflow

1. Discover allowed Codex history sources.
2. Parse and aggregate statistics with privacy protections.
3. Compute the Codex Working Persona.
4. Write `persona-illustration-prompt.txt` for a separate AI illustration.
5. If a persona illustration is supplied, pixel-process it; otherwise render a deterministic simple placeholder for development/demo.
6. Compose `receipt.html` using the texture skin and fixed layout rules.
7. Screenshot the HTML with a headless browser to create the final PNG.
8. Validate output dimensions, skin assets, dynamic height, privacy reports, and visual contract.

## Commands

```bash
python -m codex_receipt demo --out output
python -m codex_receipt generate --period all --out output
python -m codex_receipt render --out output --persona-illustration output/persona-illustration-raw.png
python -m codex_receipt inspect-coverage
python -m codex_receipt clear-cache --out output
python -m codex_receipt reset-identity --out output
python -m codex_receipt benchmark --out output
```

`--specimen-asset` remains as a backward-compatible alias for `--persona-illustration`.
